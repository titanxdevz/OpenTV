## [1.3.0] — 2026-11-10

### Added

- Hardware input switcher built on `TvInputManager`, listing HDMI and tuner
  inputs and switching to them directly.
- Slide-in settings overlay with live Wi-Fi status, SSID and a hardware input
  list.
- `AmbientView` — a soft radial accent glow that blends into the time-of-day
  sky, replacing the previous flat-fill view that erased the gradient.
- `RowIndicatorView` — a slim scroll-position indicator beneath the app row.
- `SmoothRowLayoutManager` — custom scroll physics for the app row.
- Glide disk caching for app icons and banners, so artwork renders instantly on
  the second boot.

### Changed

- Artwork is decoded as `RGB_565` at reduced dimensions, halving bitmap memory
  on ~1 GB RAM hardware.
- Cinematic backdrops are generated by downscaling to 28×16 and upscaling with
  bilinear filtering, instead of a full-resolution blur.
- Focus restoration is retried across several frames, so a cold boot no longer
  strands focus on the top bar.
- `GlassView` moves to its target on the next frame, avoiding a zero-width
  race on the first focus change.

### Fixed

- The app row no longer detaches the focused child mid-scroll, which dropped
  focus back to the top bar.
- The row indicator no longer divides by zero when only one app is installed.
- The settings overlay no longer jumps back to the home screen on dismiss.

## [1.2.0]

### Added

- `LaunchAnimator` — zoom-to-fullscreen transition when an app is launched.
- `GlassView` — spring-animated floating focus highlight using an overshoot
  interpolator.
- Palette-sampled accent colours driving the background gradient.

---

## [1.1.0]

### Added

- Glide disk cache for banners and icons.
- Launch zoom animation.
- Smooth scroll physics for the app row.
- Row position indicator.

### Fixed

- Settings and Wi-Fi buttons no longer return unexpectedly to the home screen.
- Wi-Fi status is shown inline instead of leaving the launcher.
- The hero app name is populated on first load.

---

## [1.0.0]

### Added

- Initial release: time-of-day sky gradient, live clock and greeting.
- Horizontal row of installed Leanback apps with banner or icon tiles.
- Full D-pad navigation with focus restore.
